# CommerceLake — Cloud Data Lakehouse Platform

A production-oriented data engineering portfolio project implementing Medallion Architecture using Databricks, PySpark and Delta Lake.

## Project Overview

CommerceLake processes synthetic e-commerce data through Bronze, Silver and Gold layers to deliver reliable, validated and analytics-ready datasets.

## Technology Stack

- Python
- PySpark
- Delta Lake
- Databricks Free Edition
- Unity Catalog
- Databricks Lakeflow Jobs
- SQL
- Faker
- Pytest
- Git and GitHub

## Planned Engineering Features

- Medallion Architecture
- Multi-format data ingestion (CSV, JSON, Parquet)
- Incremental batch processing
- Delta MERGE operations
- Schema enforcement and evolution
- Data quality and quarantine framework
- Idempotent pipeline execution
- Slowly Changing Dimensions (SCD Type 2)
- Dimensional data modeling
- Pipeline monitoring and audit logging
- Automated testing and performance benchmarking

## Architecture

Source Systems → Landing Zone → Bronze → Silver → Gold → Analytics
